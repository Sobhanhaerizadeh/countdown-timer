# ⏳ Countdown Timer

Einfach ein Datum auswählen und der Timer zählt automatisch runter.

## Wie es funktioniert

Datum auswählen, auf Starten klicken, fertig. Die aktuelle Uhrzeit holt sich die Seite automatisch vom Browser.

---

## Projektstruktur

```
countdown-timer/
├── index.html    ← Struktur
├── style.css     ← Styling
├── script.js     ← Logik
└── README.md
```

---

## Technologien

- HTML5
- CSS3
- JavaScript (Vanilla)

---

## Starten

`index.html` im Browser öffnen — fertig. Kein Server nötig.
